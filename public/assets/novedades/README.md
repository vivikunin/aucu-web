# Imágenes de novedades

Guardá en esta carpeta las fotos de los posteos de Novedades.

Usá nombres breves, descriptivos y sin espacios, por ejemplo:

- `jornada-consumidores-01.jpg`
- `jornada-consumidores-02.jpg`

Luego referencialas en `src/data/site.js` con una ruta como:

`/assets/novedades/jornada-consumidores-01.jpg`
