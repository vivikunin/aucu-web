# Galería de las Jornadas 2026

Guardá aquí las fotografías de las II Jornadas Internacionales de Defensa del Consumidor.

Después agregá cada imagen al arreglo `event.gallery` de `src/data/site.js` usando una ruta como:

`/assets/jornadas/2026/nombre-de-la-foto.jpg`

Incluí siempre un texto alternativo que describa brevemente la escena y las personas relevantes.
